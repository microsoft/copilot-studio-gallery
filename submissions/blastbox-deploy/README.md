# BlastBox Deploy

BlastBox Deploy packages a coordinated retail-agent team for import into another
Power Platform environment. It combines conversational agents with MCP-backed
store operations and reusable file-based skills.

## Agents

The store assistant works with inventory and policy specialists and includes
capabilities for membership, orders, warehouse inventory, refunds, points, and
customer documents.

## Import

Import the rebuilt ZIP through Power Platform, then review all connection
references and MCP endpoints before publishing. File-based skills are included
in the solution package and should be reviewed with the same care as other
submitted source files.
