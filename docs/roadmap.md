# Roadmap

The first release focuses on trustworthy static discovery, interactive graph
previews, deterministic downloads, and pull-request validation.

## Deferred

- **Ratings and discussion** — GitHub Discussions-backed reactions, comments,
  and a top-rated sort.
- **Download telemetry** — privacy-reviewed download counts and a most-downloaded
  sort.
- **Site analytics** — explicit analytics configuration and consent review.
- **Contributor automation** — badges, first-submission recognition, and bot
  comments that mention the submitted solution's author.
- **Graph reconstruction** — best-effort workflow layout for older exports that
  do not contain `metadata.associatedData.graph`.
- **Richer connector previews** — operation and schema summaries with a stricter
  privacy model.
- **Compatibility reporting** — surfaced import prerequisites, missing
  dependencies, connection references, and supported solution versions.
- **Graph comparison** — visual differences between two versions of the same
  submitted solution.
